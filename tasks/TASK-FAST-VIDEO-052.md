## 2. Context

- Owner wants videos generated by the VIP node to optionally include background music.
- The setup must be configured in Video Tools Lab and saved normally to the selected video asset.
- The saved setup must then be honored by Workspace VIP runs.
- A test music file is available at `public/musics/vprodmusic_asia_bgm-across-the-rivers-of-asia-143602.mp3`.

## 3. Scope

- In scope:
  - Add Video Tools Lab controls for enabling background music, choosing a track, setting volume, repeat behavior, and scheduling multiple track start times.
  - Persist the background music setup in the saved video edit setup.
  - Forward saved background music setup from Workspace VIP flows into `/api/audio/video-vip-processing`.
  - Validate music sources so only files under `public/musics` are accepted.
  - Mix configured music tracks into VIP final render audio without replacing the generated voice or configured original audio volume.
  - Keep remote EC2 VIP voice/render payloads compatible by sending public music source references.
- Out of scope:
  - Uploading arbitrary user music files from the browser.
  - Cloud storage-backed music libraries.
  - Non-VIP video edit render support unless the existing path naturally shares the same helper.

## 4. Acceptance Criteria

1. Video Tools Lab can save a background music setup with an enabled flag, master volume, selected track, per-track start time, per-track volume, and repeat flag.
2. Workspace VIP runs using a source asset with a saved music setup include that setup in the VIP processing request.
3. `/api/audio/video-vip-processing` accepts saved/form music setup, rejects unsafe music paths, and passes normalized tracks to the VIP render layer.
4. VIP final render mixes the generated voice, optional original source audio, and configured music tracks; repeat tracks can cover the full output, while scheduled tracks start at the configured second.
5. Focused tests, version guard, build, and diff check pass or failures are documented.

## 5. Technical Plan

1. Add shared background music types and normalization helpers for public `/musics/...` sources.
2. Extend Video Tools Lab setup state, hydration, save payload, and controls for background music scheduling.
3. Extend Workspace VIP payload building and VIP API parsing to propagate and validate background music setup.
4. Extend VIP render ffmpeg argument construction to add music inputs and mix them into the audio graph.
5. Add focused UI/source, API, Workspace, and render regression tests.
6. Bump patch version and update changelog/board evidence.
