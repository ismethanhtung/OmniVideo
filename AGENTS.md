# OmniVideo Agent Onboarding

File này dành cho AI agents: đọc nhanh để bắt đầu làm đúng quy trình trong repo.

## 1. Đọc theo thứ tự bắt buộc

1. `docs/SYSTEM-SUMMARY.md`
2. `docs/governance/ai-agent-rules.md`
3. `docs/governance/testing-rules.md`
4. `docs/governance/task-standard.md`
5. `docs/governance/definition-of-ready-done.md`

## 2. Quy tắc cứng

1. Không Task ID: không bắt đầu.
2. Không Acceptance Criteria/Test Plan: không In Progress.
3. Có code change: bắt buộc viết/cập nhật test.
4. Không test evidence: không Done.
5. Không cập nhật changelog: chưa hoàn tất task.

## 3. Chỉ mục docs đầy đủ

- Xem `docs/README.md` để điều hướng toàn bộ tài liệu.
- Xem `docs/SYSTEM-SUMMARY.md` để nắm toàn cảnh nhanh.
